# Adult CCRN Study Hub

This folder is ready to upload to GitHub Pages and embed in Notion.

## Files

- `index.html` - the Adult CCRN Study Hub app.
- `firebase-config.js` - optional Firebase config for notes/progress sync across devices.
- `DEPLOY.md` - setup steps for GitHub Pages, Notion, and optional Firebase.
- `.nojekyll` - keeps GitHub Pages from changing how the site is served.

## Notion Use

After GitHub Pages publishes the site, paste the public URL into Notion and choose `Embed`.

## Sync Note

The study content is available everywhere as soon as it is hosted. Notes, progress checks, and weak areas save on each device by default. To make those sync everywhere too, fill in `firebase-config.js` and follow the Firebase section in `DEPLOY.md`.
